# Irman Gusman — Profil Publik

Website profil publik nonresmi dengan arah visual editorial/institusional,
dibangun dengan Next.js (static export) dan Tailwind CSS.

Halaman: Beranda (Tentang, Perjalanan, Fokus, Kegiatan, Sumber), Biografi,
Berita & Kegiatan, Galeri, Dokumen.

Konten dikelola di `lib/content.ts`; panduan lengkap ada di [CMS.md](CMS.md).

```bash
npm install
npm run dev
```

Deploy otomatis ke GitHub Pages lewat GitHub Actions saat push ke `main`
(Settings → Pages → Source: **GitHub Actions**).

URL: https://ariantoekaputra99.github.io/irman-gusman-profile/

Situs ini bukan situs resmi pemerintah atau kanal kampanye. Informasi faktual
diarahkan ke sumber resmi yang ditautkan pada halaman.
